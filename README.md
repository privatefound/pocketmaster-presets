# 🎸 Pocket Master Presets

A free collection of guitar presets for the **Sonicake Pocket Master**, inspired by the tones of legendary artists and bands.

Download them, load them, play. And if the tone you want isn't here yet, **just ask** (see below).

---

| Preset | Inspired by | Style |
|---|---|---|
| [`ACDC.prst`](presets/ACDC.prst) | AC/DC | Hard rock, crunchy rhythm |
| [`Blink182.prst`](presets/Blink182.prst) | Blink-182 | Pop punk, high gain |
| [`ChetAtkins.prst`](presets/ChetAtkins.prst) | Chet Atkins | Country / fingerstyle, clean |

| [`Santana.prst`](presets/Santana.prst) | Carlos Santana | Singing lead, warm overdrive |

> 💡 Tip: tweak **volume and gain** to match your guitar. Single coils and humbuckers react very differently, so treat these as a starting point.

## ⬇️ How to use

1. Download the `.prst` file you want from the [`presets/`](presets/) folder (or clone the whole repo).
2. Connect your Pocket Master and open the official Pocket Master app.
3. Import the `.prst` file and save it to a free slot.
4. Plug in and play!

## 🙋 Want a preset? Open an issue!

**Looking for a specific tone, artist, song or genre?** 
👉 **[Open an issue](../../issues/new/choose)** and tell me what you'd like. I'll create the preset and upload it here as soon as possible.

To help me nail the sound, include if you can:
- Artist and/or song (a YouTube link is great)
- Your guitar and pickups (e.g. Strat with single coils, Les Paul with humbuckers)
- Whether it's for rhythm, lead, or both
